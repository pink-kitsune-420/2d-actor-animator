# Security reporting

A private vulnerability-reporting channel has not yet been selected. Please do not post exploit details, credentials or private actor projects in public issues. The repository owner must add and verify a private reporting channel before advertising one here. No private reporting endpoint or response-time commitment is currently offered.

The editor parses local JSON and PNG in the browser with explicit size/format limits. Keep browser software current and keep editable backups. Browser recovery is best effort storage, shared across tabs on an origin. Hosted application files come from the site; the separate offline HTML is self-contained. See [file and recovery guidance](docs/getting-started.md).
