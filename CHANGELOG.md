# Changelog

## 0.1.0a — Alpha

**Alpha software: it may not work properly.** Expect bugs, incomplete features and changes. Keep downloaded editable-source backups. GitHub marks this as a prerelease; package archives use the equivalent SemVer `0.1.0-alpha.0`.

- Simplified the Parts/Rig/Animate workspace with focused controls and beginner guidance.
- Added visible paint swatches, direct color picking and explicit palette recoloring.

- Retired the credited schematic runtime and sheet demo pages; retained independent test fixtures and the editor’s Projects examples.

- Added Runtime Contract Draft 1 semantic specification, portable analytic fixtures and fresh installed-package/browser conformance consumers over existing behavior; source and API identifiers unchanged.

- Independent 2D actor parts, layered indexed artwork, arbitrary skeletons and scene attachments.
- Visual rig and timeline editing, easing curves, cels, composition and emote previews.
- Editable source download/reopen, revision acceptance, undo/redo and namespaced local recovery.
- Reviewable sampled PNG sheets with timing, framing and pivot metadata.
- Zero-dependency DOM-free runtime and optional WebGL2 / Canvas2D rendering entries.
- Self-contained offline HTML and prepared static hosting with creator help and tutorials.

Live Space Lab provider adoption, arbitrary engine/file compatibility, phone authoring and mesh deformation are not qualified by this candidate.
