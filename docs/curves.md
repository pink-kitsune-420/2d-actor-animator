# Outgoing easing curves

In Animate, select an authored transform key in the dope sheet or precise key list. **Outgoing easing** shows the segment from that key to its next key. The last explicitly clicked member of a group is active; edits affect that one segment. Clearing selection or selecting a discrete/cel row disables the graph. Retiming/pasting selects the resulting key; deletion invalidates its handles. Last and single keys retain their inert outgoing metadata in the precise controls, with no editable outgoing graph.

The horizontal axis is normalized elapsed time (0–1); the segment label gives actual seconds. The vertical axis is eased progress, shared by all five complete local absolute TRS components. Endpoint values label x/y in project units (x right, y up), rotation in CCW radians and dimensionless scales. This is an easing graph. It does not show physical trajectories or independently keyed component tangents. Constant endpoint components stay constant even with overshoot.

A missing override inherits the track's step/linear default. Presets use the existing fixed cubic controls. Custom Bézier curves plot parametric X(s),Y(s): the evaluator solves X(s)=elapsed before evaluating Y(s). X controls independently range from 0 to 1; crossed X controls are legal. Y controls may overshoot/undershoot without changing endpoint keys. The graph fits source controls without clamping source. Step holds until the exact next key; its discontinuity is drawn explicitly.

Choose **Curve only** then **Apply curve only** to set an override. Track-default intentionally removes only curve/Bezier fields; source angle, turns, TRS, times and unrelated data remain. **Convert shown curve to custom** explicitly expands a preset into editable controls. Linear/default/step conversion starts with the identity cubic; converting a step changes its timing and is deliberate. Viewing or selecting a preset never converts it.

Drag either custom handle to stage controls. Release validates and commits once; Undo restores the complete source and Redo is exact. Pointer X stays in [0,1], Y stays within the captured fitted view. Exact numeric fields allow any finite Y, including values beyond that view; Apply custom controls refits it. Focus a handle and use arrows for 0.01 control increments, Shift for 0.1. Text inputs keep native text undo. Numeric fields require an explicit Apply; merely typing does not change source.

Escape, pointer cancellation/capture loss, blur/hidden document, external focus, task/clip/target/key/file/source changes, scroll, resize and disposal cancel staging. Source identity/epoch guards reject stale callbacks. Motion updates only SVG geometry; completion still pays whole-project source validation/compile/history costs. The graph caches its geometry and follows the existing preview clock without another animation loop.

Unwrapped rotation preserves authored radians. Shortest mode uses the arc in [-π,π) plus the starting key's explicit integer turns; an exact half turn goes negative. Eased progress may overshoot rotations, and the exact next key restores its raw authored value. Curve-only edits do not change angle mode or turns. The separate Insert/revise key controls edit complete records and track angle mode.

The graph always represents raw authored easing. Single-clip preview can solve constraints; animator preview can blend layers, masks, additive references and fades before constraint solving. Those results are never baked into keys by curve editing. The clock label distinguishes the preview modes. Existing grid, speed, onion-skin and joint aids remain available.

Composition's **Refresh diagnostics at current clock** captures layer/state entries, fade weights and scripted request outcomes on demand. The snapshot stays fixed during playback until refreshed. Transitions expose duration seconds and interrupt priority; duration zero is a cut. There is no transition-easing source field. Scrubbing evaluates the configured request script without appending requests. These editor controls introduce no source schema, runtime export or compatibility migration.
