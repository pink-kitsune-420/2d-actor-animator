# Visual clip timeline

Choose **Animate** and a clip in Preview. The dope sheet shows arbitrary rig/node and attachment names. A transform diamond is one **complete local absolute TRS** key. Visibility, painter order and reusable cels occupy separate step/hold rows. Empty rows remain available in All channels; Authored tracks and channel filters shorten the view. Row/key tooltips show full names, channel metadata and exact seconds. Cel tooltips show the next hold boundary. No frame rate is required.

Drag the seconds ruler to seek the existing preview clock. The playhead shows effective single-clip time; the status separately shows the raw preview clock for loop/ping-pong clips. A ruler seek selects that single clip. Composition remains a separate preview and is never flattened into authored keys. Seeking, selection, filtering, zoom and scrolling do not modify source or history.

Click a key to select it and populate the precise controls. Row selection shares the animation target and rig/artwork selection. Cel selections populate Cels & flipbooks. Shift-click toggles keys; dragging a selected key moves the selected group. Drag empty row space to select an inclusive time/row rectangle; Shift adds to the selection. Use Select all, Clear selection or numeric inclusive range controls as alternatives. Alt-click cycles nearby overlapping keys; the precise authored-key list also distinguishes exact times.

A drag displays a staged timing offset and commits once on release. Every selected key keeps its relative offset, complete record and outgoing curve/turns metadata. Optional snap has an explicit interval in seconds; **0 disables snapping**. The grabbed key snaps, and its delta applies to the whole group. Exact Move offset controls do not snap. All destinations must remain inside `[0, duration]`; collisions with unselected keys refuse the entire operation. There is no implicit overwrite, clamping, duration extension or target remapping. Cel retiming changes adjacent holds because their ends are the next key or clip end. Artwork, pivots, densities and accepted revisions remain untouched.

Copy keys uses an internal editor clipboard. Paste at playhead or an exact origin places the earliest copied key at that time. Full transform/step/cel records and source track metadata are retained. Pasting into another clip in the **same open project** targets the same named IDs. New tracks receive IDs unique within that clip. Existing transform tracks must have the same interpolation and angle metadata; otherwise paste refuses. Another opened/replaced project clears the clipboard, including when it reuses the same project ID. OS clipboard permissions are unnecessary.

Focus the sheet for Ctrl/Cmd A/C/V, Delete/Backspace and Ctrl/Cmd Z/Shift Z. Left/right seek one snap interval, or 0.01 seconds with snap off; Shift-left/right moves selected keys by that interval. Exact buttons/numeric controls remain available. Text fields keep native text undo. Unchanged drags create no history entry; completed edits are one whole-source Undo with exact Redo.

Escape, pointer cancellation/capture loss, blur/hidden document, another control's focus, task/target/clip/file changes, scrolling, resizing or closing the editor terminates a staged drag. Cancelled/stale callbacks cannot change source, recovery or history. Source changes elsewhere invalidate key selection; reselect the authored keys. The visual sheet follows the existing clock without rebuilding rows during playback. Large source edits still require whole-project validation/compilation on completion.

Clip settings, create/duplicate/delete and precise transform/channel controls remain available below the sheet. Deletion retains existing action/emote/composition reference guards; shortening duration cannot trim keys silently. The curve metadata controls preserve current easing support; a graphical curve editor is separate work. The timeline introduces no source schema or runtime API change.
